Возможности

Почему NeuralDeep?

Полный доступ к российским AI-моделям и сервисам, без прокси, без сторонних зависимостей.

🤖

Все модели в одном месте

Qwen 3.8, GPT-OSS, DeepSeek V4, GLM 5.3, Kimi K3, Claude 5.5 — выбирайте из каталога прямо в интерфейсе.

💰

Две системы оплаты

Подписка с фиксированной ценой или кошелёк с оплатой за токены. Переключайтесь между моделями.

🔧

Модульные сервисы

Поиск, OCR, генерация изображений, музыка, TTS, транскрипция, эмбеддинги. Включайте что нужно.

🌐

Без прокси

Прямое HTTPS-подключение к API NeuralDeep. Прокси окружения отключены на уровне транспорта.

📦

Переносимость

Linux, Windows, macOS. Python 3.10+ и Node.js 18+. Никаких глобальных зависимостей.

🛡️

Безопасность

Ключи только в .env, redaction в логах, локальный адрес 127.0.0.1, случайный токен шлюза.

Готовы начать?

Три команды — и все модели NeuralDeep доступны в Claude Code. Без зависимостей, без прокси.

$ git clone https://github.com/YOUR_USERNAME/neuraldeep-claude.git
$ cp .env.example .env # ← вставьте ключи
$ ./install.sh --activate
