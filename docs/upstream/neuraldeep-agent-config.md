# Настройки агента — neuraldeep.ru API

> Раздел машиночитаемой справки. Все разделы: https://neuraldeep.ru/llms.txt · всё одним файлом: https://neuraldeep.ru/llms-full.txt

Выберите тариф, опции и агента, затем скопируйте файл по указанному пути.

Как считаются числа:

- потоки агенту - около трёх четвертей `parallel`, остаток для других запросов с тем же ключом;
- пауза между запросами - 60 секунд, делённые на чат-RPM;
- таймаут запроса - две трети потолка гейта;
- тишина в стриме - 60 секунд;
- ретраев три, длинные окна session/week повторами не переждать.

Не каждый агент умеет задать все эти числа в файле, что применилось, видно в оговорках под конфигом.
