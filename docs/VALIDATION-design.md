# Проверка /nd-design настоящим Claude Code

Дата: 2 ноября 2026. Проверяется установленный пользовательский skill
`~/.claude/skills/nd-design/SKILL.md` в штатном Claude Code CLI 2.1.316 через
локальный NeuralDeep gateway. Это локальный skill создания файлов и ассетов;
он не выдаётся за Anthropic Design с облачным входом/синхронизацией.

Задача smoke: в отдельном каталоге создать offline HTML-лендинг Orbital Studio,
получить ровно одно изображение настоящим NeuralDeep MCP, дождаться завершения,
скачать, прочитать фактический файл и включить локальную копию в HTML. Никаких
публикаций, загрузки пользовательских файлов или установки npm/pip-пакетов.
Ключ изображения явно `subscription`; переключения на кошелёк не разрешены.

Ранние состояния проверки фиксируются в
`.local/design-validation/latest.json` и соответствующих `receipt.json`.
Последняя успешная нативная проверка после введения сетевого барьера —
`.local/offline-validation/20261102T165827430393Z/receipt.json`;
результат и точные границы описаны ниже.
Полный stream-json, stderr, debug и исходный prompt сохранены рядом; настройки
с локальным gateway-токеном имеют закрытые права и не включаются в текст отчёта.

## Обнаруженные проблемы и контрольные запуски

1. `.local/design-validation/20261102T154256Z`: с `--setting-sources ''`
   пользовательский skill не попал в native `init.skills`. Реальный
   `Skill{skill:nd-design}` вернул `Unknown skill: nd-design`. Запуск остановлен
   до генерации изображения. Чтение SKILL.md вручную не засчитывается за
   успешную нативную команду.
2. `.local/design-validation/20261102T154500Z-user-source`: с
   `--setting-sources user` skill появился в `init.skills`; реальный вызов Skill
   успешно сообщил `Launching skill: nd-design`. Read прочитал runtime;
   параллельные Read/Bash завершились, но нового API-вызова и файлов затем не
   было более двух минут. Запуск остановлен на ~320 с до изображения.
   В debug видна синхронизация существующих пользовательских plugins и таймауты
   first-party telemetry, однако причинная связь с остановкой не доказана.
3. `.local/design-validation/20261102T155101Z-isolated-plugins`: короткий
   технический запуск с выключенными только для теста plugins остановлен для
   добавления полного контроля `disableAllHooks=true`; не засчитывается как
   функциональная проба.

Контрольный сценарий использует `--setting-sources user`, минимальные явные
настройки маршрута, `--strict-mcp-config` только с NeuralDeep MCP, отключённые
**только во временном файле теста** plugins/hooks, последовательные вызовы для
однозначного сопоставления шагов. Производственные plugins/hooks и возможности
параллельной работы этим не изменяются. Таймаут одного полного сценария — 600 с.

В двух первых запусках повторно используемого Python-harness
(`20261102T155228Z-controlled`, `20261102T155843Z-controlled`) обнаружена ошибка
самого harness: дочерний CLI унаследовал открытый stdin. Эти init-only пробы
**невалидны для вывода о CLI или модели**. В последующих запусках явно задан
`stdin=subprocess.DEVNULL`. Отсутствие debug-строки `[API:request]` само по себе
тоже не доказывает отсутствие запроса: для проверки используется фактический
`gateway-events.jsonl` и, где доступно, состояние сокетов процесса.

## Готовый артефакт: диагностический bare-сценарий

`20261102T160051Z-controlled`, Claude Sonnet 5.5 через явно выбранный ключ
кошелька, штатный `claude --bare`, local API-key шлюза, stdin=DEVNULL: процесс
завершился успешно за 94 с. **Этот режим не предоставил native Skill tool**:
модель прямо сообщила об этом и прочитала установленный SKILL.md вручную.
Поэтому его результат не считается доказательством нативного `/nd-design`
полного цикла.

Он доказал работающий прикладной путь inference + MCP + файлы:

- Ровно один `image_generate`, `billing=subscription`, ID
  `9af24259-11eb-431c-b817-5595dacaf4b6`.
- Статусы processing → finished, ожидание `sleep 4`, скачивание тем же ключом.
- Реальный файл изображения прочитан инструментом Read до использования.
- Созданы `site/index.html`, `site/assets/hero.png`, `site/README.txt`.
- Независимая статическая проверка: PNG signature, размер 1024×576, непустой
  файл; все локальные ресурсы/якоря/aria-controls существуют; внешних URL и форм
  нет; inline JavaScript проходит `node --check`.

Готовая страница:
`.local/design-validation/20261102T160051Z-controlled/site/index.html`.
Независимый отчёт — `static-validation.json` в том же каталоге запуска.
Изображение также непосредственно осмотрено: тёмный космический пейзаж с
планетой и тонкой орбитальной дугой, без текста.

**Реальный расход NeuralDeep не следует брать из `total_cost_usd` Claude CLI.**
В результате CLI `costBasis=list` — оценка по прайсу Anthropic, а не отчёт
платёжной системы NeuralDeep.

## Проверка основного профиля и оставшиеся границы

Повторные normal-сценарии используют тот же готовый image task, запрашивают
status/result и Read и не создают новых изображений. Последний запуск
`20261102T161401Z-main-no-persist` использует фактический основной профиль,
`--model nd/claude-sonnet-5.5@wallet~max`, `--no-session-persistence`,
stdin=DEVNULL и не подменяет settings/sources/bare/MCP. Финальный запуск
остановлен по новому запрету пользователя на любые обращения к Anthropic
примерно на 500-й секунде, exit 143. После его начала в `gateway-events.jsonl`
не появилось запросов этого сценария к NeuralDeep, новых tool calls/файлов не
было. Поэтому факты «нативный Skill успешно вызван» и «в bare получены HTML и
готовый ассет» остаются разными частями доказательств.

Остановлен только наш Claude PID 2515523 и его дочерние MCP/tool-процессы;
подтверждение `.local/design-validation/STOP-20261102.json`. Shared relay и
соседние приложения не затронуты. До установки сетевого барьера новых
native-запусков после запрета не было. На этом историческом этапе
односессионный native Skill → MCP image → HTML путь не был подтверждён;
прикладной bare-путь и отдельный вызов native Skill были разными доказательствами.
Следующая проверка выполнена только после установки сетевого барьера.

Попытка открыть готовую страницу через CUA по `file://` отклонена URL-политикой
браузера: разрешены HTTP/HTTPS, и ответ прямо запрещает обход через косвенные
способы. Обходов, raw Playwright/CDP и публикации не выполнялось. Визуальная
проверка страницы в браузере, мобильные/десктопные скриншоты и реальные клики
FAQ/contact **не подтверждены**. Статическая проверка кода не выдаётся за такие
UI-проверки.

Все изменения ограничений plugins/hooks/allowed-tools были временными
настройками smoke-процессов; производственные ограничения из них не создавались.
Прямой режим относится к запросам NeuralDeep внутри адаптера. Общесистемные
proxy, shared relay, ChatGPT и Codex этим тестом не изменялись.

## Успешный native Skill → Read → HTML в изолированной сети

`20261102T165827430393Z`, штатный CLI 2.1.316, модель
`nd/qwen3.8-27b@subscription~xhigh`, 149,47 с, exit 0, финал
`DESIGN_OFFLINE_OK`. Этот запуск закрыл пробел нативного исполнения skill:
в одной сессии настоящий инструмент `Skill` запустил `nd-design`, настоящий
`Read` прочитал уже существующий PNG, `Bash` скопировал его, а CLI создал новый
`site/index.html` и `site/README.txt`. Новый платный image task не создавался;
использован неизменённый ассет успешной предыдущей генерации. HTTP-операции
NeuralDeep MCP в этой проверке явно запрещены; все 14 MCP инициализировались
со статусом `connected`. В `init.skills` присутствуют `nd-design` и `nd-workflow`.

Результат:
`.local/offline-validation/20261102T165827430393Z/site/index.html`.
HTML — 10 339 байт; PNG — 398 342 байта, 1024×576, SHA-256
`9ac942db2e07a7ecede4d8bdb4e03b1489beb724fbc68b8047ea0f06dfa7bc74`.
Независимая `static-validation.json` проверила локальные ресурсы, существование
якорей, уникальность ID, alt изображения и responsive media query. Есть
`mailto:`-ссылка-заглушка, она не нажималась; внешних загружаемых ресурсов нет.
Визуальная проверка в браузере по-прежнему не заявляется.

Процесс запущен **только** внутри `bwrap --unshare-net`; до запуска ELF проверены
отличающийся network namespace и единственный интерфейс `lo`. Временный
Unix-мост допускает только host `127.0.0.1`, порты 8787 и 18790. Inference
прошёл через 11 фактических запросов локального шлюза; `strace` зафиксировал
22 TCP connect, все к loopback. Успешных и неразрешённых внешних подключений —
0; у host egress guard внешних подключений `connected` — 0. Собственная группа
процессов и Unix socket удалены. Общий relay, proxy Codex/ChatGPT и настройки
других приложений не менялись. Полный trace, границы policy, хеш бинарника,
точная копия скрипта и receipt сохранены в каталоге запуска.

Это доказательство ограниченного Linux-теста. Оно не выдаётся за постоянный
сетевой sandbox производственного CLI на всех ОС. Подробности базовой
проверки, защитных условий и повторения — `docs/VALIDATION-offline.md`.
