# Сеть и настройки Claude

Текущий выбор пользователя: служебную активность Claude уменьшать обычными конфигурационными флагами, без собственного сетевого фильтра и дополнительных proxy-обёрток.

- Оригинальная команда `claude` сохраняется. Основной `ANTHROPIC_BASE_URL` указывает на локальный NeuralDeep gateway; в настройки попадает локальный gateway token, а ключи провайдера остаются только в `.env`.
- Штатные обновления CLI разрешены: `autoUpdates=true`. Интеграция не устанавливает `DISABLE_AUTOUPDATER` или общий `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC`, поскольку они мешают updater.
- Телеметрия и отчёты об ошибках отключены отдельными штатными флагами. Установщик формирует для Desktop `disableEssentialTelemetry=true` и `disableNonessentialTelemetry=true`; независимый `disableNonessentialServices=false` сохраняет connector icons, hosted artifact previews, MCP App widgets и Linux spellcheck. Для этих возможностей разрешены их обычные служебные запросы; переключатель не влияет на inference и не считается исправлением отправки Code.
- Desktop получает `disableAutoUpdates=false`. В проверенной Linux-сборке приложение обновляется через системный пакетный менеджер; этот флаг не создаёт отдельный Linux updater. На Windows/macOS интеграция не блокирует штатный updater. `installedUpdateEnforcementEnabled=false` сохраняет отключённым принудительный restart после внешней установки обновления.
- Model catalog metadata включены; `modelCatalogUrl` не переопределяется. Приложение обновляет подписанный каталог с `https://downloads.claude.ai/model-catalog/v1/catalog.json` и использует свой штатный cache. `bootstrapEnabled` также не переопределяется; без `bootstrapUrl`, который установщик не добавляет, bootstrap config не запрашивается. Этот путь не связан с account `/api/bootstrap`.
- Gateway и NeuralDeep MCP используют `ProxyHandler({})` и не отправляют запросы через proxy окружения. В `.env` проекта нет proxy-переменных. Локальный API исключён из proxy через NO_PROXY.
- Desktop launcher и отдельный `claude-neuraldeep` запускают gateway и приложение, не устанавливая network guard. Независимый браузер использует собственный Chromium без отдельного сетевого фильтра.
- Общий relay `127.0.0.1:20171`, upstream `nl.notevil.ai:8888`, service, drop-in, независимый конфиг и настройки Codex/ChatGPT находятся вне изменений установщика. Порт 8790 также не используется интеграцией.

Это конфигурационные флаги приложения, а не абсолютный запрет всех соединений Anthropic. Штатный updater, обязательные проверки браузера или подготовка Code engine могут обращаться к инфраструктуре производителя по обычным правилам приложения. Искусственной блокировки этих путей больше нет.

Здесь описана конфигурация, формируемая текущим установщиком. Изменение исходников само не применяет её к live-профилю и не перезапускает открытый Desktop.

На этом компьютере эти четыре прежних ограничения отдельно сняты в сохранённом
профиле 2026-11-02 в 23:35 Europe/Moscow, с резервной копией. Запись находится в
`.local/native-policy-migration.json`. Приложение при этом не перезапускалось;
это не доказывает перечитывание всех настроек уже открытым окном или исправление
Code Send. При следующем обычном запуске будет загружена новая конфигурация.

Пользователь отдельно включил подписной title helper:
`desktop_title_model=nd/qwen3.6-35b-a3b-noreason@subscription` в
`config/helper-models.json`. Это явное правило gateway для точных generic/coding
title-шаблонов native Desktop 4.4212.0. Оно проверяет полный управляющий prompt и
строгую форму запроса; неизвестные формы, обычный Code и explicit effort не
перенаправляются. Основная модель и Auto permission checks сохраняются.
Helper допускает только точный базовый subscription ID, без wallet fallback;
неверный выбор завершается ошибкой до обращения к провайдеру. Ответ содержит
фактически использованный helper ID, метрики — исходный `requested_model` и
`helper_rule`, без описания сессии и полного prompt. Значение `null` отключает
правило на следующих совпавших вызовах: gateway читает поле при их обработке.
Отдельный `auto_permission_classifier` передаётся Desktop при запуске процесса,
поэтому изменение именно классификатора требует перезапуска приложения.

Живая проверка обоих точных title-запросов прошла по одной попытке: coding
0,587 с, generic 4,487 с при native deadline 15 с. Источник:
`.local/title-helper-validation/20261103T062835785874Z/review.json`. Это проверка
gateway с искусственными описаниями, а не завершённая полная Desktop-сессия.

Отмена клиентского SSE-запроса вызывает `socket.shutdown()` для его реального
upstream-сокета и освобождает занятый слот. Локальные HTTP integration tests
проверяют разрыв во время ожидания заголовков и чтения остановившегося тела.
Новых временных или token caps этот механизм не вводит. Обнаружение разрыва
зависит от неудачной записи события или keepalive; до завершения DNS/TCP/TLS
setup сокет ещё не привязан, поэтому действует прежний connect timeout.

Дополнительно пройден отдельный локальный TLS smoke: отмена при ожидании
заголовков и при чтении тела. В обоих случаях подтверждены закрытие provider
socket, завершение worker, `active_requests=0` и повторное использование слота.
Проверка сертификата и hostname включена с тестовым доверием только временному
сертификату. Доказательства:
`.local/cancellation-validation/20261103T063419380230Z/review.json`.
Это два дополнительных TLS-сценария; основной unittest suite содержит три
HTTP integration tests для cancellation.

Старый принадлежащий интеграции фильтр на 18790 остановлен через его собственный idle shutdown. Модуль и прежние изолированные probes сохранены как диагностическая история; обычная установка и запуск от них не зависят. Ранее полученные receipts с guard описывают прежний режим и не являются текущей production-политикой.

Sandbox команд Claude Code выключен в конфигурации. Electron launcher получает `--no-sandbox`; VM Advanced file analysis сохранена по выбору пользователя. Права устройств ОС и системные группы не меняются.
