# Браузер для публичных сайтов

В Claude подключается отдельный MCP-сервер **local-browser** на официальном Microsoft Playwright MCP. Он открывает публичные сайты, читает accessibility snapshot, нажимает элементы, заполняет формы, выполняет JavaScript и Playwright, снимает скриншоты, сохраняет PDF и предоставляет сетевые инструменты. Встроенный браузер Claude Desktop используется для локальных превью; публичные страницы доступны через local-browser.

Текущая закреплённая версия — `@playwright/mcp@0.0.84`. Версия и требование Node.js 18+ проверены по [официальному npm registry](https://registry.npmjs.org/@playwright%2fmcp/0.0.84). Использованы [официальная конфигурация](https://playwright.dev/mcp/configuration/options) и все семь дополнительных [групп возможностей](https://playwright.dev/mcp/capabilities): `network`, `storage`, `testing`, `vision`, `pdf`, `devtools`, `config`. Базовые инструменты, включая выполнение кода, также доступны. Проверенный установленный сервер публикует 72 инструмента.

## Установка и включение

Нужны Python 3.10+ и стандартный Node.js 18+ с npm в `PATH`. Общая установка проекта устанавливает браузер автоматически, если сервис `browser` включён. Отдельные команды из каталога проекта:

```console
python scripts/browser-mcp.py install
python scripts/browser-mcp.py status
python scripts/nd.py services disable browser
python scripts/nd.py services enable browser
```

На Windows при необходимости используйте `py -3` вместо `python`. На macOS и Linux — установленный `python3`. Сборка не использует shell-скрипты npm: npm запускается своим JavaScript entry point, что позволяет работать с Windows `.cmd` и путями с пробелами.

После изменения набора MCP-серверов перезагрузите MCP или откройте новую сессию Claude. Выключение `browser` также закрывает уже запущенный этой интеграцией MCP-процесс: оболочка проверяет переключатель каждые 250 мс. Другие браузеры и общий сетевой relay не затрагиваются.

Пример задания Claude:

> Открой публичную страницу через local-browser, прочитай snapshot, проверь нужные элементы и сохрани полный скриншот. Для локального сайта сначала запусти сервер разработки и открой его localhost URL.

Все файлы принадлежат каталогу проекта:

- `.local/browser-runtime/` — npm-проект, lockfile, npm cache, конфигурация, receipt установки и Chromium.
- `.local/browser-output/` — снимки, PDF и остальные автоматически именованные результаты.

Установка не устанавливает системный Chrome, не использует `install-deps`/`--with-deps`, не меняет пользовательский npm-конфиг и не читает API-ключи из `.env`. На Linux необходимы обычные системные библиотеки Chromium. Если их нет в минимальном образе, запуск выдаст ошибку отсутствующих библиотек; автоматического изменения ОС нет. На новом компьютере заново выполните установку: Chromium скачивается под его ОС и архитектуру, переносить бинарные файлы между платформами не нужно.

## Профиль и сеть

Каждый MCP-процесс запускает собственный Chromium с `--headless`, `--isolated`, `--no-sandbox`, всеми перечисленными возможностями и без таймера простоя. Профиль создаётся временно, существующие браузеры, расширения, cookies и сохранённые логины пользователя не подключаются. Разные MCP-процессы могут работать параллельно со своими изолированными профилями.

На каждом запуске оболочка заново записывает настройки Chromium и очищает proxy-переменные только в окружении своего дочернего процесса. Отдельный proxy, сетевой фильтр и вспомогательный guard браузеру не нужны. Родительское окружение, общий relay `127.0.0.1:20171`, его конфигурация и настройки Codex/ChatGPT не меняются.

Служебные обращения самого Claude к Anthropic выключаются конфигурационными флагами Claude. Браузер работает с обычными публичными сайтами; отдельной блокировки доменов Anthropic или сетевой изоляции здесь нет.

## Проверка этой установки

Актуальный локальный протокол проверки: `.local/browser-validation/direct-receipt.json`. Через настоящий MCP проверены initialization, список 72 инструментов, открытие `https://example.com`, accessibility snapshot и PNG полного экрана. PNG находится в `.local/browser-output/direct-example.png`. Проверка `browser_get_config` подтверждает отдельный изолированный Chromium с выключенным sandbox, без собственного proxy и сетевого фильтра.

Это исполненная проверка на Linux; Windows и macOS используют те же переносимые команды и платформенную загрузку Playwright, но в этой сессии на них не запускались. Более ранний `receipt.json` относится к отменённой конфигурации с guard и не описывает текущую установку.
